## 5. 트러블슈팅

## 이슈 1: 모바일에서 팝업 카드가 잘려 보이고 닫기 버튼을 쓰기 어려움

- **문제**: 모바일 화면에서 품종 상세 팝업의 상단 부분이 잘려 보이고, 닫기 버튼을 찾기에 어려움이 생김
- **원인**: 팝업 화면이 화면보다 작아서 본문 내용이 잘리고 닫기 버튼이 고정되어있지 않아 생긴 문제였음
- **해결**: 화면 스크롤 시 초반에 팝업이 화면 전체를 덮도록 바꾸고, 팝업 안의 본문이 그다음으로 스크롤되도록 프롬프트를 다시 작성해 수정. 추가로 닫기 버튼을 상단에 고정해 빠르게 메인으로 돌아갈 수 있게 보완했음.

## 6. AI 활용 방식

**맡긴 일**:

- 이미지 생성 (Flow · 나노바나나)
- 자료 정리 (Claude): 브랜드 코드, 브랜드 개요, 사이트맵
- 바이브코딩 (Claude): Figma 화면을 바탕으로 React 화면 구현

**핵심 프롬프트 (이미지)**: Create a sophisticated and minimal website hero visual for a premium aquatic brand named "Fin&Co.", inspired by the attached reference image.
**핵심 프롬프트 (자료정리)**: 웹사이트를 만들 거야.
목표: 구현전에 사이트 목적을 구체화하기
역할: 질문하고 답변을 정하는 UX 기획자
진행: 먼저 나에게 필요한 정보를 질문 기능으로 하나씩 물어봐줘.
한 번에 한 질문씩, 내 답변을 반영해 다음 질문을 해줘. 선택지와 추천 안을 함께 작성해 줘.

## 7. 회고

- **배운 점과 아쉬운 점**: Ai가 만든 코드를 그대로 쓰다 보니 디자인의 세부적인 부분을 놓치는 경우가 있었다. 이는 사이트 히어로 섹션부터 푸터까지 꼼꼼히 살펴가며 수정 및 보완을 했고, ai를 어느 정도로 신뢰해야 좋은 결과물이 나오는지 알 수 있었다. 또한 ai에게 프롬프트를 요청할 때 어느 정도로 구체적인 글을 작성해야 원하는 결과가 나오는지 가늠할 수 있었다.
