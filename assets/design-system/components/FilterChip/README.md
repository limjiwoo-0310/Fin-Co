# FilterChip

입양 가능 개체(S-06)의 색·패턴별 찾기 옵션이며, 같은 모양을 입양 신청서의 선택 옵션에도 씁니다.

- 선택됨: `navy-900` 채움, 흰 글자 14px 500. 신청서 안에서는 `ink` 채움.
- 선택 안 됨: 1px `line-control` 테두리, 흰 바탕, `text` 글자 400.
- 높이 40px(신청서 44px), 좌우 20px, 간격 `space-2`, `radius-0`.
- 한 번에 하나만 선택하고, 첫 옵션("전체")이 기본 선택입니다. `aria-pressed`로 상태를 알립니다.
- 주의: `line-control` 테두리는 흰 바탕 대비 1.6:1로 3:1에 못 미칩니다.
