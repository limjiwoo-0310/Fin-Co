# Button

버튼은 세 가지이며, 면을 채운 주요 버튼은 핵심 행동(입양 신청하기 B-13)에만 씁니다.

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| Primary | `navy-900` 채움, 흰 글자 16px 600, 높이 56px | 입양 신청하기 |
| Secondary | 1px `navy-900` 테두리, 흰 바탕, `navy-900` 글자 15px 500, 높이 `control-h` | 세트·용품 보기, 입양 가능 개체 보기, 심화 사육 정보 보기, 사육 가이드 보기 |
| Hero | 흰 바탕, `navy-700` 글자, `radius-pill`, 높이 `control-h-lg`, 오른쪽 화살표 | 첫 화면 품종 도감 보기 하나 |

- 모서리는 `radius-0`. Hero만 예외입니다.
- 이동 버튼에는 오른쪽 화살표(1.6px 선)를 붙일 수 있습니다. 돌아가기는 왼쪽 화살표.
- 버튼 문구는 결과를 말합니다. 한 묶음에 주요 버튼은 하나만 둡니다.
- 사용하는 쪽이 정할 것: 문구, 연결할 섹션·페이지.
