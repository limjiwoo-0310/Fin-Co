# BreedCard

품종 도감(S-04)과 입양 가능 개체(S-06)의 사진 카드이며, 사진을 주인공으로 두고 글은 최소로 둡니다.

| 종류 | 크기 | 내용 | 마우스를 올리면 |
| --- | --- | --- | --- |
| 품종 | 폭 336, 사진 높이 300 | 사진 · 품종 이름(`card-title`)만 | 1.045배 확대, 배경 그대로 |
| 개체 | 폭 306, 사진 세로 3:4(400) | 사진 · 색 계열 태그 · 이름 16px · 설명 2줄 | `hover-tint` 면 |

- 흰 바탕, 테두리 없음, `radius-0`. 사진 자리는 `photo-ground`.
- 카드 전체가 하나의 버튼이며, 누르면 상세 팝업(P-02·P-03)이 열립니다.
- 카드에 가격은 넣지 않습니다. 입양비는 개체 상세 팝업에만 있습니다.
- 사용하는 쪽이 정할 것: 사진, 이름, (개체) 색 계열과 설명.
