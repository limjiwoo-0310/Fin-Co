## 1. 프로젝트 개요

### 1-1. 목적
- 품종 도감에서 베타의 특징을 살펴보고, 마음에 드는 베타의 난이도와 적정 환경을 확인한 뒤 입양 신청까지 한 곳에서 할 수 있게 합니다.
- 슬로건: **"알고 고르는 베타, Fin&Co."**
- 전달할 인상: 단정하고 정리된, 믿을 수 있는 브랜드
- 피할 방향: 대형 쇼핑몰 느낌, 생명을 상품처럼 다루는 느낌, 유치하고 가벼운 느낌

### 1-2. 방문자가 원하는 것

| 방문자 | 비중 | 원하는 것 |
| --- | --- | --- |
| 첫 베타 입문자 | 우선 | 품종별 난이도 비교, 적정 환경 안내(사육 환경·먹이 급여 방법), 필요한 세트와 총비용 |
| 베타 애호가·수집가 | 보조 | 색·패턴별 찾기, 희귀 품종·입고 소식, 심화 사육 정보 |

- 주요 기기: PC 우선, 모바일은 기본 대응

### 1-3. 핵심 행동
- **핵심 행동:** 입양 신청 — P-03 개체 상세 팝업 안의 신청서(F-02)를 B-13으로 제출하면 실제 전송 없이 P-04 완료 화면을 보여 줍니다.
- **보조 행동:** 베타 정보 알아보기 → 관련 상품 구매(실제 구매 없이 안내 메시지만 표시)
- **주요 동선:** S-04 품종 도감 → (B-02) → P-02 품종 상세 → (B-11) → S-06 입양 가능 개체 → (B-06) → P-03 개체 상세·입양 신청 → (B-13) → P-04 입양 신청 완료

## 2. 요구사항 표

- 우선순위 기준: **상** = 안 되면 방문자가 입양 신청(핵심 행동)을 못 하거나, "알고 고르는" 주요 기능(품종 비교·품종 상세·신청 전 개체 확인)을 쓰지 못함 / **중** = 입양 판단을 돕는 정보·탐색, 모바일 대응 / **하** = 보조 탐색·부가 기능
- 순서: P-01(S-01 → S-10) → P-02 → P-03 → P-04 → P-05 → 공통. 도착 화면이 같은 버튼은 한 줄로 묶었습니다.
- 기대 결과는 별도 표기가 없으면 데스크탑(폭 1440px) 기준입니다.
