## 표기 기준

| 요소 | 그리는 방법 |
|---|---|
| 텍스트 | P-01: 회색 선 (제목은 진한 굵은 선, 본문은 연한 얇은 선) / P-02~P-05: 실제 문구 초안 ("문구 초안 · 확인 필요" 표시) |
| 이미지 | X 상자 |
| 버튼 | 실선 테두리 박스 + 라벨 |
| 핵심 행동 | 굵은 검정 테두리(3px) + "핵심 행동" 표시 → `B-13 입양 신청하기` |
| 입력·선택 | 입력칸(테두리 박스), 선택칸(▾ 표시), 선택 옵션(둥근 버튼, 선택된 것은 진하게) |
| 조절 (가로 스크롤) | 카드 한 줄 + 오른쪽 끝 카드가 잘려 보임 + 아래 스크롤 막대(진한 부분이 현재 위치) |
| 목록 | 썸네일 + 텍스트 선이 구분선으로 이어진 행 |
| 추후 결정 | 점선 박스 + "추후 결정" 표시 |
| ID | 검정 태그 — M 메뉴 · P 페이지 · S 섹션 · B 버튼 · F 입력/선택/조절 |

- 카드·목록 개수는 자리 표시예요. 품종 도감 6개, 입양 가능 개체 8개(문서 기준 6~8마리), 세트·용품 3개, 입고 소식 3개로 그렸어요.

## 2. 문구 초안 (P-02~P-05)

Figma에 넣은 문구와 같아요. 모두 **초안**이라 확인이 필요해요.
- 품종(하프문)과 개체(하프문 · 로열 블루)는 화면을 보여 주기 위한 예시예요.
- 개체 정보 항목, 신청 폼 항목, 심화 콘텐츠 주제는 사용자가 쓴 사이트 구조 초안(초안.txt)을 따랐어요.
- 사육 수치(수온 · 어항 크기 · 환수량)는 일반적인 베타 사육 기준이에요. 게시 전에 확인해 주세요.

### P-02 품종 상세 팝업
- **S-11 품종 요약**
  - 품종명: 하프문
  - 영문명: Halfmoon
  - 키우기 난이도: 보통
  - 소개: 꼬리지느러미를 활짝 펴면 반달처럼 180도로 펼쳐지는 품종이에요.
- **S-12 특징**
  - 꼬리지느러미가 넓고 길어 헤엄치는 모습이 우아해요.
  - 지느러미가 무거워 물살이 센 곳에서는 쉽게 지쳐요.
  - 지느러미가 찢어지지 않도록 끝이 날카로운 장식물은 피하는 게 좋아요.
- **S-13 적정 환경**
  - 수온: 24~28℃ · 히터 사용 권장
  - 어항: 10L 이상 권장
  - 여과기: 물살이 약한 스펀지 여과기
  - 합사: 수컷은 한 어항에 한 마리
- **버튼:** B-11 "하프문 입양 가능 개체 보기", B-12 "닫기 ✕"

### P-03 개체 상세 팝업 · 입양 신청
- **S-14 개체 정보**
  - 개체 이름: 하프문 · 로열 블루
  - 품종: 하프문
  - 색·패턴: 로열 블루 솔리드
  - 성별: 수컷
  - 나이: 약 4개월
  - 입양비: ○○,000원 ([추후 결정] 금액)
- **S-15 품종 난이도·환경 요약**
  - 키우기 난이도: 보통
  - 요약: 수온 24~28℃ · 어항 10L 이상 · 물살이 약한 환경에서 키워 주세요.
- **S-16 입양 신청 폼**
  - 제목: 이 개체 입양 신청하기
  - 안내: 아래 항목을 작성해 주세요.

- **S-20 심화 콘텐츠 (F-05 아코디언)**

  | 질병 대처 | 접힘 ("＋ 펼치기") | 지느러미 녹음, 백점병처럼 흔한 질병의 증상과 초기 대처 방법 |

  | 발색·컨디션 관리 | 접힘 | 먹이 구성, 조명, 스트레스 관리로 색을 선명하게 유지하는 방법 |
