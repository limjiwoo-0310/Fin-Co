## 1. 디자인 방향

| 항목 | 내용 |
|---|---|
| 방향 이름 | 수조 표본실 — 흰 바탕에 베타 사진을 표본처럼 띄우고, 남색 하나로 정리하는 편집샵형 화면 |
| 전달할 인상 | 단정하고 정리된, 믿을 수 있는 (01-site-purpose.md) |
| 피할 방향 | 대형 쇼핑몰 느낌, 생명을 상품처럼 다루는 느낌, 유치하고 가벼운 느낌 (01-site-purpose.md) |
| 핵심 원칙 | 흰 바탕 위 베타 사진이 주인공 · 포인트 색은 남색 하나 · 큰 제목 + 작은 본문 + 넓은 여백 · 모서리는 직각 · 움직임은 첫 화면에만 |

### 5-4. 선택 옵션 · 항목 목록

- 찾기 옵션(F-01): 선택된 것은 `navy-900` 채움, 나머지는 `line-control` 테두리. 높이 40px, 직각. 첫 옵션 "전체"가 기본 선택이에요.
- 신청서 선택 옵션(F-02): 같은 모양, 선택된 것은 `ink` 채움, 높이 44px.
- 항목 목록("항목명: 값"): 항목명 열 88px, 항목명 `ink` 600 · 값 `text` 400, 구분선 없음. P-02 S-13, P-03 S-14·S-15에 같은 형식으로 써요. S-05 적정 환경은 큰 숫자(26px 600 `navy-900`) 2×2 + 수온 막대(20~32℃ 중 24~28℃)로 바꿨어요 (사용자 승인 11/13).
- 희귀 품종 표시·색 계열 태그: 직각 작은 박스, `tag` 글자.

## 6. 분위기와 톤

- 한 줄 설명: **깔끔하게 설명하는 톤.** 짧은 합니다체로, 꾸밈말과 감탄 없이 확인된 사실만 써요.
- 예시 문장: "카드를 선택하면 품종별 특징과 적정 환경을 확인할 수 있습니다."

| 쓰기 | 쓰지 않기 |
|---|---|
| 기본 세트에 큰 어항과 조명을 더한 구성입니다. | 지금 바로 특가로 만나는 업그레이드 세트 |
| 입양 신청이 완료되었습니다. | 축하해요, 새 가족이 생겼어요! |

- 제목은 명사형으로 끝내요: "함께할 베타 찾기", "사육 환경 가이드".
- 방문자가 직접 고르는 선택지("처음이에요", "준비했어요")만 해요체로 둬요.
- 문서에 없는 사실(가격, 기능, 후기)은 쓰지 않아요. 빈자리는 `[가상 금액]`, `[문구 필요]`로 표시해요.
