# 인터랙션 목록 · 모바일 처리 제안

> 분석 기준: `src/` 아래 JSX·JS·CSS 전체 (2026-11-16). 코드는 수정하지 않았습니다.

## 먼저 확인된 사실

- **모바일용 레이아웃 기준점(`@media (max-width…)`)이 프로젝트에 하나도 없습니다.** 지금 있는 미디어 쿼리는 `prefers-reduced-motion`(움직임 줄이기 설정)과 `hover`/`pointer`(마우스·터치 판별)뿐입니다.
- 커서 마크, 히어로 물결, 세트 카드 기울기는 이미 JS에서 터치 기기면 꺼집니다. 하지만 CSS `:hover` 효과는 막혀 있지 않습니다. 그래서 터치 기기에서 탭한 뒤 hover 상태가 화면에 남을 수 있습니다.
