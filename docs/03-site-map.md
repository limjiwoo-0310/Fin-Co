## 1. 계층도

```
Fin&Co. (알고 고르는 베타, Fin&Co.)
├─ [페이지] 메인 원페이지 — 스크롤형 한 페이지 · PC 우선 · 상세는 팝업
│   ├─ 상단 메뉴 (공통) — 메뉴 → 해당 섹션으로 이동
│   │   └─ [추후 결정] 메뉴 항목 · 고정 여부
│   │        ① 품종 도감 / 사육 가이드 / 입양 / 세트·용품
│   │        ② ① + 입고 소식
│   ├─ 첫 화면 — 슬로건 "알고 고르는 베타, Fin&Co."
│   ├─ [추후 결정] 브랜드 소개 — 섹션을 넣을지
│   ├─ 품종 도감 — 6개 품종 카드, 카드마다 난이도 표시
│   │   └─ [팝업] 품종 상세 — 키우기 난이도 · 특징 · 적정 환경
│   │        "이 품종 개체 보기" → 입양 가능 개체
│   ├─ 사육 가이드 — 적정 사육 환경 · 먹이 급여 방법
│   │    섹션 끝: 추천 세트 · 총비용 / 링크 → 심화 사육 정보
│   ├─ 입양 가능 개체 — 입양 가능 개체 6~8마리, 색·패턴별 찾기
│   │   └─ [팝업] 개체 상세 — 개체 정보, 품종 난이도·환경 요약
│   │       ├─ 입양 신청 폼 — 팝업 안에서 신청, 제출 시 완료 메시지만 표시 (실제 전송 없음)
│   │       └─ [추후 결정] 신청 완료 후 다음 행동
│   ├─ [추후 결정] 입양 절차 안내 — 섹션을 넣을지
│   ├─ 세트·용품 — 세트 · 관련 용품
│   │   └─ [추후 결정] 관련 상품 구매 방식
│   ├─ 입고 소식 — 입고 소식 · 희귀 품종 포함
│   └─ 푸터 — 링크 → 심화 사육 정보
└─ [페이지] 심화 사육 정보 — 별도 페이지 · 애호가·수집가 대상
     들어오는 곳: 사육 가이드 링크, 푸터 링크
    ├─ [추후 결정] 심화 콘텐츠 주제·구성
    └─ 메인으로 돌아가기 링크 → 메인 원페이지
```

## 2. 페이지 간 이동

| 출발 | 이동 | 도착 |
|---|---|---|
| 상단 메뉴 | 메뉴 클릭 | 메인의 해당 섹션 |
| 품종 도감 | 품종 카드 클릭 | 품종 상세 팝업 |
| 품종 상세 팝업 | "이 품종 개체 보기" | 입양 가능 개체 |
| 입양 가능 개체 | 개체 카드 클릭 | 개체 상세 팝업 |
| 개체 상세 팝업 | 입양 신청 | 팝업 안의 입양 신청 폼 |
| 사육 가이드 | 링크 | 심화 사육 정보 |
| 푸터 | 링크 | 심화 사육 정보 |
| 심화 사육 정보 | 돌아가기 링크 | 메인 원페이지 |

## 3. 하단 패널 A — 상세 페이지 분리 여부

| 항목 | 처리 방식 | 상태 | 근거 |
|---|---|---|---|
| 품종 상세 | 별도 페이지로 나누지 않고 팝업으로 표시 | [확정] | 02 §4 · 목록 위치를 유지한 채 여러 품종을 비교 |
| 개체 상세 | 별도 페이지로 나누지 않고 팝업으로 표시 | [확정] | 02 §4 · 목록 위치를 유지한 채 여러 개체를 비교 |
| 심화 사육 정보 | 유일한 별도 페이지 | [확정] | 02 §1, §4 · 입문자 화면은 단순하게, 애호가용 정보는 분리 |
| 사이트 형태 | 메인 원페이지 + 상세 팝업 + 별도 페이지 1개 | [확정] | 01 §2 · 6개 품종, 6~8마리, PC 우선 / 02 §1 |
