## 1. 사이트 형태 [확정]

- 메인 원페이지 + 상세 팝업
- 별도 페이지 1개: 심화 사육 정보

| 구분 | 구성 |
|---|---|
| 메인 원페이지 | 첫 화면 / 품종 도감 / 사육 가이드 / 입양 가능 개체 / 세트·용품 / 입고 소식 / 푸터 |
| 팝업 | 품종 상세, 개체 상세(입양 신청 폼 포함) |
| 별도 페이지 | 심화 사육 정보 |

## 2. 방문자 행동 흐름

| # | 방문자 행동 | 필요한 정보·기능 | 배치할 페이지·섹션 | 다음 행동 |
|---|---|---|---|---|
| 1 | 사이트에 처음 들어옴 | 베타 전문 브랜드, 슬로건 "알고 고르는 베타, Fin&Co." | 메인 · 첫 화면 | 품종 도감 보기 |
| 2 | 품종을 비교함 (입문자) | 6개 품종의 특징, 품종별 난이도 비교 | 메인 · 품종 도감 | 품종 상세 팝업 열기 |
| 3 | 한 품종을 자세히 봄 | 난이도, 특징, 적정 환경 | 품종 상세 팝업 | 이 품종의 입양 가능 개체 보기 / 사육 가이드 보기 |
| 4 | 키울 수 있을지 확인함 | 적정 사육 환경, 먹이 급여 방법 | 메인 · 사육 가이드 | 필요한 세트 확인 / 입양 가능 개체 보기 |
| 5 | 준비물과 비용을 확인함 | 필요한 세트, 총비용 | 메인 · 사육 가이드 끝 추천 세트 → 세트·용품 | 관련 상품 구매 (구매 방식은 추후 결정) / 입양 가능 개체 보기 |
| 6 | 마음에 드는 개체를 찾음 | 입양 가능 개체 6~8마리, 색·패턴별 찾기 | 메인 · 입양 가능 개체 | 개체 상세 팝업 열기 |
| 7 | 개체를 자세히 봄 | 개체 정보, 해당 품종의 난이도·환경 요약 | 개체 상세 팝업 | 입양 신청 |
| 8 | 입양을 신청함 (가장 중요한 행동) | 신청 폼, 완료 메시지 (실제 전송 없음) | 개체 상세 팝업 안의 신청 폼 | [추후 결정] |
| 9 | 희귀 품종·입고 소식을 확인함 (애호가) | 입고 소식, 희귀 품종 | 메인 · 입고 소식 | 입양 가능 개체 보기 |
| 10 | 심화 사육 정보를 봄 (애호가) | 심화 사육 정보 | 별도 페이지 · 심화 사육 정보 | 메인으로 돌아가기 |
| 11 | 원하는 곳으로 바로 이동함 | 섹션 바로가기 메뉴 | 상단 메뉴 (메뉴 항목은 추후 결정) | 해당 섹션으로 이동 |

## 3. 메인 섹션 순서 [확정]

1. 첫 화면
2. 품종 도감
3. 사육 가이드 (끝에 추천 세트)
4. 입양 가능 개체
5. 세트·용품
6. 입고 소식
7. 푸터

## 4. 고른 대안과 이유 [확정]

| 항목 | 고른 대안 | 이유 |
|---|---|---|
| 사이트 형태 | 메인 원페이지 + 상세 팝업 + 별도 페이지 1개 | 콘텐츠 양(6개 품종, 6~8마리)이 적고 PC 우선이라, 알아보기부터 입양까지 한 흐름으로 이어져요. |
| 품종·개체 상세 | 팝업 | 목록에서 보던 위치를 유지한 채 여러 품종·개체를 비교할 수 있어요. |
| 난이도 비교 | 도감 카드마다 난이도 표시 | 입문자가 도감을 훑어보는 동안 바로 난이도를 비교할 수 있어요. |
| 입양 신청 위치 | 개체 상세 팝업 안의 신청 폼 | 어떤 개체를 신청하는지 분명하고 단계가 적어요. |
| 심화 사육 정보 | 별도 페이지 | 입문자 화면은 단순하게 두고, 애호가용 정보는 분리해요. |
| 세트·용품 노출 | 사육 가이드 끝 추천 세트 + 별도 세트·용품 섹션 | 보조 행동인 관련 상품 구매를 지원하면서, 뒤쪽에 둬서 쇼핑몰 느낌을 피해요. |

## 5. 추후 결정

### 구조
- 상단 메뉴 항목: ① 품종 도감 / 사육 가이드 / 입양 / 세트·용품, ② ①에 입고 소식 추가
- 상단 메뉴를 스크롤해도 고정할지
- 브랜드 소개 섹션을 넣을지
- 입양 절차 안내 섹션을 넣을지
- 입양 신청 완료 후 다음 행동

### 콘텐츠
- 품종 도감에 넣을 6개 품종 목록
- 개체 상세에 보여줄 정보 항목
- 입양 신청 폼 항목
- 세트 구성과 총비용 기준
- 입고 소식에 보여줄 범위
- 심화 사육 정보의 주제와 구성
- 섹션별 실제 문구

### 운영·기능
- 관련 상품 구매 방식
- 이미지 출처
- 모바일 대응 수준 (현재는 PC 우선만 확정)
