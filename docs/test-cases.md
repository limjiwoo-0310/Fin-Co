## 1. 테스트 케이스 표

**테스트 전에 읽어 주세요**

- **화면 크기:** 따로 적지 않은 케이스는 PC에서 마우스로, 브라우저 창 가로 폭 1440px로 확인합니다. TC-20 · TC-22만 폭 375px 터치 기기(휴대폰)로 확인합니다.
  - 폭 맞추는 방법(Chrome): `F12`로 개발자 도구를 열고 `Ctrl + Shift + M`(기기 모드)을 누른 뒤, 화면 위쪽 가로 폭 칸에 1440 또는 375를 입력합니다. 375px 확인은 실제 휴대폰으로 해도 됩니다.
- **"처음 화면"** = 배포 주소를 새 탭에서 열었을 때 보이는 첫 화면(큰 베타 사진 위에 "알고 고르는 베타, Fin&Co." 문구)입니다.
- **메인 페이지 순서:** 메인은 한 페이지를 아래로 스크롤하며 봅니다. 위에서부터 처음 화면 → "다양한 베타 모아보기" → "사육 환경 가이드" → "함께할 베타 찾기" → "어항 세트와 관련 용품" → "새로 들어온 베타" → 맨 아래 회색 영역 순서이고, 각 영역은 큰 제목으로 찾습니다.
- **상단 메뉴:** 화면 맨 위 줄입니다. 왼쪽에 "Fin&Co." 로고, 오른쪽에 "품종 도감 · 사육 가이드 · 입양 · 세트·용품" 메뉴가 있습니다.
- **팝업:** 카드를 누르면 화면 가운데에 흰 창(팝업)이 뜨고 뒤쪽은 어두운 회색으로 덮입니다. 팝업 오른쪽 위 ✕가 닫기 버튼입니다.
- **괄호 안 기호:** S-04, B-13 같은 기호는 `prd.md`와 맞춰 보기 위한 번호입니다. 테스트할 때는 화면에 보이는 글자로 찾으면 됩니다.
- **결과 칸:** 기대 결과의 문장이 모두 맞으면 "통과", 하나라도 다르면 "실패"로 적습니다.
- TC-01 ~ TC-20은 요구사항별 케이스, TC-21 · TC-22는 핵심 행동(입양 신청)을 끝까지 해내는 사용 흐름 케이스입니다.
