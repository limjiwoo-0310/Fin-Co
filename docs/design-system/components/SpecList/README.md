# SpecList

"항목명: 값"을 한 줄씩 보여 주는 목록이며, 적정 환경(S-05, P-02 S-13), 개체 정보(P-03 S-14), 난이도·환경 요약(S-15)에 같은 형식으로 씁니다.

- 2열 그리드: 항목명 열 88px, 간격 16px, 행 간격 14~16px.
- 항목명 `ink` 15px 600, 값 `text` 15px 400, 줄 간격 1.6. 구분선 없음.
- 흰 바탕 또는 `mist` 면 위에 둡니다(요약은 `mist` 면, 안쪽 여백 24·28px).
- 확인 전인 수치는 묶음 제목 옆에 "초안 · 게시 전 확인"을 `text-muted` 11px로 표시합니다.
- 사용하는 쪽이 정할 것: 항목과 값. 값이 없으면 `[값]`으로 둡니다.
