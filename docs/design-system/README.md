# Fin&Co.

베타 전문 어항 브랜드 Fin&Co.(핀앤코)의 웹사이트 디자인 시스템입니다. 슬로건은 "알고 고르는 베타, Fin&Co."입니다. 이 문서는 디자인 캔버스의 메인 페이지(P-01), 팝업(P-02·P-03·P-04), 심화 사육 정보(P-05)에 지금 적용된 값을 정리한 것입니다. 값을 바꿀 때는 캔버스와 이 문서를 함께 고칩니다.

- 전달할 인상: 단정하고 정리된, 믿을 수 있는
- 피할 방향: 대형 쇼핑몰 느낌, 생명을 상품처럼 다루는 느낌, 유치하고 가벼운 느낌
- 방향 이름: **수조 표본실**. 흰 바탕에 베타 사진을 표본처럼 띄우고, 남색 하나로 정리하는 편집샵형 화면입니다.

## 말투

깔끔하게 설명하는 톤입니다. 짧은 합니다체를 쓰고, 꾸밈말과 감탄 없이 확인된 사실만 씁니다.

| 쓰기 | 쓰지 않기 |
| --- | --- |
| 카드를 선택하면 품종별 특징과 적정 환경을 확인할 수 있습니다. | 귀여운 베타 친구들을 만나 보세요! |
| 기본 세트에 큰 어항과 조명을 더한 구성입니다. | 지금 바로 특가로 만나는 업그레이드 세트 |
| 입양 신청이 완료되었습니다. | 축하해요, 새 가족이 생겼어요! |

- 제목은 명사형으로 끝냅니다: "함께할 베타 찾기", "사육 환경 가이드".
- 방문자가 직접 고르는 선택지(입양 신청서의 "처음이에요", "준비했어요")만 해요체로 둡니다.
- 가격, 기능, 후기처럼 기획 문서에 없는 사실은 쓰지 않습니다. 비어 있는 자리는 `[가상 금액]`, `[문구 필요]`처럼 대괄호로 표시합니다.
- 버튼 문구는 결과를 말합니다: "품종 도감 보기", "입양 신청하기", "사육 가이드 보기".

## 색

흰 바탕이 기본이고, 색은 베타 사진에서 나오게 합니다. 포인트는 `navy-900` 한 가지입니다.

- `navy-900`: 로고, 메뉴, 섹션 제목, 버튼 테두리, 선택된 찾기 옵션, 첫 화면 배경. **면을 채운 버튼은 입양 신청하기(B-13)처럼 핵심 행동에만** 씁니다.
- 첫 화면은 `navy-900` 면 위에 `white` 글자와 흰 버튼을 올린 반전 구성입니다. 첫 화면 밖에서는 남색 면을 넓게 쓰지 않습니다.
- `mist`: 사진이 없는 정보 묶음에만 씁니다. 사진 카드(품종·개체·세트)는 항상 흰 바탕입니다.
- `fog`: 푸터에만 씁니다.
- 본문은 `text`, 보조 글자는 `text-muted`, 강조 라벨은 `ink`입니다. 모두 흰 바탕과 `mist` 위에서 4.5:1 이상입니다.
- `line-control`(선택 안 된 옵션·입력칸 테두리)은 흰 바탕 대비 1.6:1로 컨트롤 테두리 기준 3:1에 못 미칩니다. 현재 화면 값을 그대로 옮겼고, 조정이 필요합니다.

## 글꼴

Noto Sans KR 한 가지를 씁니다. 획에 장식이 없고 끝이 둥글지 않은 글꼴입니다. Google Fonts에서 300·400·500·600·700 굵기를 불러옵니다.

- 크기 차이를 크게 둡니다. 큰 제목, 아주 작은 본문, 넓은 여백이 기본입니다.
- 극단적으로 큰 글자(`hero-light`·`hero-bold`, 88px)는 첫 화면에서만 씁니다.
- 슬로건은 같은 크기에서 1줄 300, 2줄 700으로 굵기만 바꿔 브랜드명을 강조합니다.
- 섹션은 `eyebrow`(영문 대문자, 자간 0.22em) → `section-title` → `body-lg` 한 줄 순서로 시작합니다.
- 큰 제목은 자간을 좁히고(-0.03~-0.04em), 작은 영문 라벨은 넓힙니다.

## 레이아웃

- 여백은 넓게 씁니다. 섹션 위아래는 `space-section`(120px), 본문 폭은 `content-max`(1200px), 좌우 여백은 `space-10`(40px)입니다.
- 섹션 순서는 와이어프레임을 따릅니다: 상단 메뉴 → 첫 화면 → 품종 도감 → 사육 가이드 → 입양 가능 개체 → 세트·용품 → 입고 소식 → 푸터.
- 품종 도감과 입양 가능 개체의 카드 줄만 화면 끝까지 이어지고, 마지막 카드가 잘려 보입니다. 넘김은 얇은 남색 스크롤 막대 하나로 표시하고 화살표는 두지 않습니다.
- 카드는 테두리 대신 여백으로 구분하고, 같은 줄의 카드는 같은 크기로 둡니다.
- 정보는 "항목명: 값" 형식으로 통일합니다. 항목명은 `ink` 600, 값은 `text` 400, 넓은 줄 간격, 구분선 없음.
- 입고 소식은 `mist` 면이 화면 가로 전체를 채웁니다.

## 모서리와 반복 요소

`radius-0`이 기본입니다. 카드, 이미지, 정보 묶음, 버튼, 옵션, 입력칸, 팝업 모두 직각입니다.

- 주요 버튼: `navy-900`으로 채움, 흰 글자. 입양 신청하기(56px 높이, 팝업 폭 전체)가 대표입니다.
- 보조 버튼: 1px `navy-900` 테두리, 흰 바탕, 높이 `control-h`.
- 첫 화면 버튼: 흰 바탕, `navy-700` 글자, `radius-pill`. 사이트에서 유일하게 둥근 요소입니다. 다른 버튼과 맞출지 정해야 합니다.
- 찾기 옵션: 선택된 것은 `navy-900`으로 채움, 나머지는 `line-control` 테두리.
- 사진 위 태그와 희귀 품종 표시: 직각 작은 박스, `tag` 글자.

## 인터랙션과 움직임

움직임은 첫 화면 한 곳에만 쓰고, 나머지는 마우스를 올렸을 때와 눌렀을 때만 반응합니다.

| 위치 | 반응 |
| --- | --- |
| 첫 화면 | 라벨 → 슬로건 → 버튼 순서로 0.3초 간격, 14px 아래에서 떠오름(0.9초) |
| 품종 카드 | 마우스를 올리면 1.045배로 커짐(0.35초). 배경색은 바꾸지 않음 |
| 개체·세트 카드 | 마우스를 올리면 `hover-tint` 면이 생김(0.25초) |
| 카드 줄 | 끌어서 넘김, 스크롤 막대(`navy-900` 위치, `line` 트랙) |
| 팝업 | `scrim` 위 가운데 모달, 닫으면 원래 위치 |
| 구매 버튼 | 화면 아래 안내 메시지 2.4초 |

움직임을 줄이도록 설정한 방문자(prefers-reduced-motion)에게는 등장과 확대를 끕니다.

## 이미지

- 품종·개체 사진: 무료 스톡 사진. `photo-ground` 바탕 위에 베타 한 마리.
- 첫 화면·분위기 이미지: AI 생성 이미지. 베타 한 마리를 오른쪽에 두고 왼쪽은 슬로건 자리로 비웁니다.
- 개체 카드는 세로 3:4, 품종 상세 팝업 사진은 406×220, 개체 상세 팝업 사진은 720×314입니다.

## 로고

반원과 점으로 만든 마크 + "Fin&Co." 글자입니다. 반원은 하프문 꼬리가 180도로 펼쳐진 모양에서 왔습니다. 글자는 600 굵기에 "&"만 300으로 가늘게 씁니다. 흰 바탕에는 남색, 첫 화면 위에는 흰색 마크를 씁니다(Logos). 로고는 아직 제안 단계입니다.
